# IVE Cosmic Archive

A self-contained responsive prototype for an unofficial IVE fansite, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly in a browser, or use a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Included

- Responsive cosmic-control-room homepage
- Six member profile cards with abstract image placeholders
- Interactive era timeline
- Selectable media-transmission panel
- Random song picker
- Mini era-personality interaction
- Bias access-card generator
- Prototype fan-message section
- Motion toggle and reduced-motion support
- Keyboard focus states and semantic landmarks
